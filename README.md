## What is Calculadora de Reticula Editorial?

This tool lets you experiment with how an editorial grid comes together from actual measurements. Change the paper size, margins, column count, or gutter width and the layout and visual rhythm of the page update immediately.

Design students, instructors, and anyone who needs a quick reference while planning print layouts or mockups will find it practical. Because the focus is educational, it connects grid theory to the everyday workflow of Adobe InDesign, including typographic system equivalences and conversions.

---

## Features

- Live grid calculation and on-screen visualization as you edit values.
- Paper format presets plus support for custom dimensions.
- Controls for margins, columns, gutters, and the baseline grid.
- Interactive canvas where individual layers can be toggled on or off.
- Typographic unit conversion between PostScript/DTP and Didot.
- Built-in teaching aids that explain what each parameter does.
- InDesign-oriented equivalences for practical handoff.
- Single-page interface that keeps the workflow continuous and direct.

## Usage

1. Pick a paper format from the presets, or enter a custom size.
2. Set margins, columns, gutters, and the baseline grid to match your needs.
3. Watch the canvas to check how the page is visually distributed.
4. Toggle layers to compare structures and confirm proportions.
5. Look up the typographic equivalences when moving between PostScript/DTP and Didot.
6. Use the resulting measurements as a guide for preparing documents and mockups in an InDesign-like workflow.
